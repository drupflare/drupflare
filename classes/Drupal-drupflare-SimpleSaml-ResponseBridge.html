SimpleSaml

\Drupal\drupflare\SimpleSaml ResponseBridge

Makes SimpleSAMLphp's CGI habits work in a request that has no SAPI to send headers.

Only active when simplesamlphp_auth is enabled. SimpleSAMLphp:

  • redirects with header('Location'), an echoed page and exit. An exit ends the request before the host can answer it (the serve answers 500, no JSON in the output), so it is turned off with the library's own SIMPLESAMLPHP_TEST_NOEXIT constant, and the header is read back from headers_list() here and turned into the response;
  • serves its endpoints from a web server alias, which a route cannot stand in for because they have a variable depth, so they are answered from the request event;
  • saves its session, and sets the session cookie, from a header_register_callback that only a SAPI sending headers runs, so the session is saved explicitly before the headers are read;
  • expects _include.php to have installed its SAML2 container, which Drupal never includes.
