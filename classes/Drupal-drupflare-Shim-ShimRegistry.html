Shim

\Drupal\drupflare\Shim ShimRegistry

Every C-library function this runtime is asked for, and what happens to it.

Three verdicts and no fourth. A function is ROUTED over a platform primitive, REFUSED with a named reason, or -- if it is not in this table at all -- refused anyway, because an unlisted function is one nobody has thought about and guessing is how a wrong answer ships.
