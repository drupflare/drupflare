\Drupal\drupflare Host

The single seam between PHP and the Worker runtime.

Every capability in this module goes through here rather than reaching for vrzno_env() itself, for two reasons. The bridge is 32-bit (PHP_INT_SIZE 4) so anything above 2^31 has to cross as a codec envelope or a string, and a capability that forgets is a silent corruption rather than an error. And a host function may simply be absent -- a Worker deployed without an email binding has no cfwMail -- so "is this capability available" has exactly one answer, here, instead of one per plugin.
