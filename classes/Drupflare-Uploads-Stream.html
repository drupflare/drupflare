\ Drupflare_Uploads_Stream

The `public://` scheme over the host file store, which is where uploads live.

WordPress writes to wp-content/uploads with ordinary file functions, and the interpreter's filesystem lasts one request. This wrapper sends the same calls to the file store the Drupal wrapper uses, so a file is committed when the write returns. It does not stream: a write buffers until the handle closes and a read fetches the whole file.
