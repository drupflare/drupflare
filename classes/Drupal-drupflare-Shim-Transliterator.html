Shim

\Drupal\drupflare\Shim Transliterator

The Transliterator class for the one rule family Drupal code asks ICU for, over core's tables.

The build carries no ext-intl, and the ICU data behind a general transliterator is too large to ship. What contrib code actually calls is Any-Latin; Latin-ASCII, optionally followed by Lower(), Upper() or [:Nonspacing Mark:] Remove, to turn a title into ASCII. Core's PhpTransliteration produces exactly that output from its own data files. Every other rule is refused by name, and create() answers NULL the way ICU does for an ID it does not know.
