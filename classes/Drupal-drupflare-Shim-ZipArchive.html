Shim

\Drupal\drupflare\Shim ZipArchive

The ZipArchive class in PHP, over ext-zlib, for a build without ext-zip.

The runtime aliases the global name to this class on first use, so new \ZipArchive() and a subclass of it both resolve here. Exports (webform, node export, content sync), minisite uploads and phpspreadsheet's xlsx reader and writer use the surface below: open, add, read by name or index, stat, extract and close. Entries are stored or deflated; ZIP64, encryption and split archives are refused by name, because a silently truncated archive reads as a smaller one.

The archive lives in memory between open() and close(), and close() writes it back through whatever stream wrapper the path names, so temporary:// and private:// work unchanged.
