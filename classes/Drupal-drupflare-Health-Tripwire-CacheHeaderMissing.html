Tripwire

\Drupal\drupflare\Health\Tripwire CacheHeaderMissing

Asserts that a render reports which cache tier produced it.

This is RULE 3 of the measurement rules turned into a runtime assertion. A dozen figures across three rounds of this project were page_cache hits wearing a render's label, and the check that would have caught every one of them is reading x-drupal-cache before believing the number. A response with no cache header is one nobody can attribute after the fact.
