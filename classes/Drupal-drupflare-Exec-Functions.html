Exec

\Drupal\drupflare\Exec Functions

The PHP process functions, answered by {@see Router}.

The runtime removes the built-ins through disable_functions and declares each name as a thin call into one of these. A command the router serves runs and reports its own exit code; a line it refuses, or a program outside its table, is a failed launch: false and exit code 127.
