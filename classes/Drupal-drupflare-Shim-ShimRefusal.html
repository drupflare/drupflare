Shim

\Drupal\drupflare\Shim ShimRefusal

Thrown when a shimmed function cannot be served, carrying WHAT and WHY.

THIS IS THE POINT OF THE WHOLE LAYER. A silent empty return is indistinguishable from a real empty result: curl_exec() returning FALSE reads as "the server said nothing", and openssl_digest() returning FALSE reads as "unsupported algorithm". Both are what a caller sees when the truth is "no sockets here" or "crypto.subtle has no md5". That ambiguity is this project's signature failure shape, and it is why every refusal here names itself instead.

The message always contains the function name and a reason, so a log line is enough to diagnose without a debugger -- which matters because there is no debugger on the edge.
