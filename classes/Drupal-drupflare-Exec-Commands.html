Exec

\Drupal\drupflare\Exec Commands

The programs {@see Router} serves without the network.

Each takes the argv after the program name and a context (cwd, stdin, env, fetch) and answers [stdout, stderr, exit code]. An option a program does not take here throws {@see \Drupal\drupflare\Exec\Refused} by name rather than being ignored.
