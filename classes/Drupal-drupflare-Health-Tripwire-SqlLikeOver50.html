Tripwire

\Drupal\drupflare\Health\Tripwire SqlLikeOver50

Pre-flights a LIKE or GLOB pattern against the host's 50-byte ceiling.

MEASURED by bisection: 50 bytes succeed, 51 fails with "LIKE or GLOB pattern too complex: SQLITE_ERROR", against SQLite's own default of 50,000 -- the runtime lowers it by three orders of magnitude.

The check runs on the TRANSLATED pattern, and that detail is the whole point: bracket-quoting a metacharacter expands it threefold, so 20 asterisks become a 60-byte GLOB pattern and fail where the input looked safe. It binds plain LIKE too, which the driver cannot intercept -- a Views "contains" filter on a long search string fails inside the engine.
