Moves an upload the host parsed, which move_uploaded_file refuses.

PHP moves a file only when its path is in the table of this request's uploads, and only a real POST SAPI fills it. The request parser lists the files it wrote in $GLOBALS['__cfw_uploads'], so this accepts the same set PHP would. A sideload is left to WordPress, which copies it.
